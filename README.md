# Kashaf Gafoor — Portfolio

Static site: open `index.html` in any modern browser. No install, build or server required.

```
index.html
css/style.css
js/script.js
assets/images/   ← put the portrait here
assets/icons/    ← favicon
```

## Adding the portrait
Save a genuine photo as `assets/images/portrait.jpg` (portrait orientation, ~4:5, ≈1000×1250px, < 300 KB).
Until it exists, the hero shows an elegant monogram placeholder automatically.
